Create a modern, elegant, responsive **Vercel-compatible landing page** for a crochet bouquet business called:

# Crafts by Criselyn

The website is for a small handmade crochet bouquet business. The overall design should feel **cute, elegant, warm, feminine, handmade, and premium**, while still being clean and modern.

## TECHNICAL REQUIREMENTS

* Make the website fully compatible with **Vercel deployment**.
* Use a modern frontend stack such as **Next.js + React + Tailwind CSS**.
* Make it fully responsive for:

  * Desktop
  * Tablet
  * Mobile
* Optimize the website for fast loading and good performance.
* Use reusable components.
* Keep the code clean and organized.
* Do NOT require a backend or database for the landing page.
* Do NOT create unnecessary authentication or admin functionality.
* The website should work immediately after installing dependencies and running the project.
* Make sure all images use proper responsive sizing and do not break the layout.
* Use the existing photos located in the project/assets folder. **Do not replace the existing product photos with random stock images.**
* Automatically organize the provided product photos into attractive product/gallery sections.

## BRAND

Business Name:

**Crafts by Criselyn**

Primary theme:

**White + Soft Pink**

Suggested visual direction:

* White backgrounds
* Soft blush pink
* Light rose/pink accents
* Very subtle beige/cream accents
* Dark gray text
* Elegant typography
* Soft shadows
* Rounded cards
* Lots of whitespace
* Subtle floral/crochet-inspired decorative elements

The website should NOT look like a generic ecommerce template.

It should feel like a **handmade boutique brand**.

# ANIMATION REQUIREMENTS

Use modern, subtle animations throughout the website.

Recommended:

* Fade-in on page load
* Scroll reveal animations
* Image fade/scale
* Card hover lift
* Image hover zoom
* Button hover transitions
* Smooth scrolling
* Navbar transition on scroll
* Floating decorative crochet/flower elements
* Gentle hero image animation
* Lightbox transition

Animations should feel:

**soft + elegant + premium**

Avoid:

* Excessive bouncing
* Fast flashing animations
* Distracting effects
* Too many simultaneous animations

Use CSS animations or a lightweight animation library such as Framer Motion if appropriate.

Respect `prefers-reduced-motion`.
